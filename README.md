# TRUSTMEST // Investigative Provenance & Verification Workspace
Enhanced Newsroom & OSINT Fact-Checking Prototype

## Integrated Architectural Pillars
1. **Meedan Check Integration**: Isolated claim cards, assignees, multi-reviewer verification statuses.
2. **ConvergePanel Decision Receipts**: Cryptographic legal backing, audit trail, cross-referenced databases.
3. **DocumentCloud / ProofAnchor Evidence Bundling**: Immutable SHA-256 hashes, web archive links, stealth edit protection.
4. **Trust Identity Protocol (TIP) & JTI**: Transparent lineage tracking, Before/After diffs, and public transparency notices.

## Contents
- `/schemas/`: Production-grade JSON schemas for Claims, Evidence, Decision Receipts, and Lineage.
- `/receipts/`: Exported Decision Receipts for certified claims.
- `/evidence_manifests/`: Cryptographic SHA-256 manifests for source material.
- `/architecture/`: Full 4-pillar architectural specifications.
